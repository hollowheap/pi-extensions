# pi-hello

Example Pi coding agent extension. Registers a `hello` model tool and a `/hello` command.

Copy this package (`npm run new -- pi-<name>`) to start a new extension.

## Try it

```bash
pi -e ./packages/pi-hello
```

Then run `/hello` or ask the model to use the `hello` tool.

## Install

```bash
pi install npm:@my-scope/pi-hello
```
