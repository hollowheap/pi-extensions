# `@hollowheap/pi-ui`

Host-aware UI helpers for Pi extensions.

This extension-side support package contains dialogs, notifications, fuzzy
pickers, Markdown pagers, cancellable progress overlays, settings dialogs,
sandbox settings, and the code viewer. It depends on `@hollowheap/tui` for
host-agnostic rendering primitives.

Import helpers from subpaths such as `@hollowheap/pi-ui/host`,
`@hollowheap/pi-ui/pager`, and `@hollowheap/pi-ui/settings`.

This package is not registered as a standalone extension.
